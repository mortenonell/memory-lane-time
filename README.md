# Countdown Charm

Make a calendar app that adds widgets showing a countdown to pre-defined events, google calendar linkable. In the app you can create events, sync with google calendar, and set wallpaper (Adds an option to pick random wallpapers from a set album on user-defined time, changed with a drop-down menu showing every 1 minute, 5 minutes, 10 minutes, 15 minutes, and every time the phone is turned on (if possible, otherwise on unlock).

The widgets have a background that the user can set: It can be colors or pictures. 
Add in big text "X [TIME] to [EVENT]" with 'X' being the amount of days/weeks/months/years - defined by 'TIME' - to the 'EVENT' in question.
Add the event in the widget under the big pre-defined message in small text.
Make the text color changeable by the user as well.

Also make the app add notification options for each individual event.
